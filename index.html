Conexão com Nuvem Gratuita (Firebase Realtime Database) Desconectado (Apenas Local)

Passo a passo rápido (leva 2 minutos e é 100% gratuito):

1 Ativar Nuvem no Firebase (Google)

Acesse console.firebase.google.com com sua conta Google, crie um projeto, clique em Criação → Realtime Database → Criar banco de dados e escolha Iniciar no modo de teste. Copie o link gerado (terminado em .firebaseio.com) e cole no campo acima.

2 Publicar e Instalar no Celular

Baixe este arquivo HTML, renomeie para index.html e arraste em app.netlify.com/drop. Abra o link gerado no celular, conecte o mesmo link do Firebase acima e toque em Adicionar à tela inicial no navegador para usar como aplicativo!
