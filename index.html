Tabela utilizada no banco: oab_progress

SQL para criar a tabela no Supabase (Cole no SQL Editor do Supabase e clique em Run): 

create table if not exists oab_progress (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);

alter table oab_progress enable row level security;
drop policy if exists "Acesso Publico OAB" on oab_progress;
create policy "Acesso Publico OAB" on oab_progress for all using (true) with check (true);

Depois de rodar o SQL, vá em Project Settings → API no Supabase, copie a Project URL e a anon key e cole nos campos acima.
